# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project, please report it responsibly
by emailing **evamxb@uw.edu**.

Please do **not** open a public GitHub issue for security-related concerns.

We will acknowledge your report within 48 hours and aim to provide a fix or
mitigation within 7 days of confirmation.

## Scope

This package makes HTTP requests to external grant database APIs. It does not
handle authentication credentials, store sensitive data, or run a web server.
Security concerns are most likely related to dependency vulnerabilities.
